# ETS4 behavioral evaluations

This directory contains versioned human-review criteria, not deterministic unit tests or gold labels generated by a model.

`cases/synthetic_forecast_combination_v1.md` is a fixed fictional study designed to exercise panel differentiation, information-set integrity, overlapping-horizon inference, structural-change interpretation, reproducibility, and the untrusted-manuscript boundary. Its JSON companion describes behavioral probes but contains no gold labels.

Build its disposable PDF and run a review with:

```bash
python evals/build_case_pdf.py \
  evals/cases/synthetic_forecast_combination_v1.md \
  /tmp/ets4-synthetic-forecast-combination-v1.pdf
ets4 review /tmp/ets4-synthetic-forecast-combination-v1.pdf \
  --provider openai --model MODEL_NAME --referees 4
```

Run ETS4 into ignored `runs/`, then score current runs with `criteria-v3.json`. It covers two-step Stage 1 plus the referee and final-editor `1.2.0` prose format. Keep versions 1 and 2 for runs using older prompt formats. Record the case version, generated manuscript hash, run fingerprint, provider/model configuration, prompt versions, evaluator, evidence, and any critical failure.

Live provider calls are opt-in, cost-bearing, and never part of default CI.
